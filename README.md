Repositorio oficial de proyectos finales de la materia **Sistemas Programables**  
Ingeniería en Sistemas Computacionales · Instituto Tecnológico de León (TecNM)

Cada semestre los equipos diseñan y construyen sistemas IoT completos aplicados a  
problemas reales de **inclusión social y computación cognitiva**, integrando:

- 🔧 **ESP32 + MicroPython** — firmware embebido
- 📡 **MQTT + Mosquitto** — comunicación en tiempo real
- 🧠 **IA en servidor Python** — OpenCV, MediaPipe, TensorFlow Lite
- 🔥 **Firebase + Firestore** — histórico en nube y dashboard

> Los proyectos se entregan como **productos físicos funcionales**.  
> No se aceptan maquetas, simulaciones ni protoboards sin carcasa.

## ⚡ Stack tecnológico del curso

```
ESP32 / ESP32-CAM  ──MicroPython──▶  publica sensores + frames vía MQTT
                                              │
                                    Broker Mosquitto (local o nube)
                                              │
                                    Servidor Python (PC del equipo)
                                    IA: OpenCV / MediaPipe / TFLite
                                              │
                              ┌───────────────┴──────────────┐
                              ▼                              ▼
                     Publica cmd MQTT              Escribe en Firebase
                              │                              │
                     ESP32 activa                   Dashboard web
                     actuador físico               en tiempo real
```
